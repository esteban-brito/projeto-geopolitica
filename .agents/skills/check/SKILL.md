# /check — Auditoria das 13 Guardas

Executa as 13 guardas arquiteturais do projeto:

- `annexes`, `boundaries`, `cascade`, `codenames`, `identity`, `material`, `motion`, `naming`, `orphans`, `prose`, `schema`, `tokens`, `vocabulary`.

## Procedimento

1. Execute no terminal:
   `npm run check`
2. Verifique se as 13 guardas estão verdes.

⚠ **O número de provas sintéticas não se escreve aqui** — ele muda a cada guarda que aprende
um defeito novo. Quem o declara é `docs/handoff.md`, e quem o conta é a própria saída.
