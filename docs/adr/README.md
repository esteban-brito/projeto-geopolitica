# Decisões

Uma ADR registra uma decisão que não se reabre sem pedido do Diretor: o contexto, a decisão, o
porquê, as consequências e as emendas, datadas. Cada uma abre com a linha de situação, que diz o que
vale hoje.

| decisão                                                                                  | situação | o que vale hoje                                                                 |
| ---------------------------------------------------------------------------------------- | -------- | ------------------------------------------------------------------------------- |
| [0001 — a IA fica fora do turno](0001-ai-stays-out-of-the-turn.md)                       | aceita   | nenhum modelo de linguagem no turno nem no jogo; IA por API não entra           |
| [0002 — a IA gera vocabulário, nunca efeito](0002-ai-generates-vocabulary-not-effect.md) | aceita   | a IA escreve vocabulário revisado fora do jogo; número derivável nunca é gerado |
| [0003 — o mundo é real, as pessoas são inventadas](0003-real-world-invented-people.md)   | aceita   | nome inventado; os papéis do 1º ano se inspiram no real, sem nome nem episódio  |
